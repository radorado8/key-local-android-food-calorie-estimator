# USDA Common Foods starter list

`usdaCommonFoods.json` contains 1,000 foods with energy, protein, carbohydrate and fat values per 100 g. It is derived from the USDA FoodData Central SR Legacy (April 2018) download.

USDA FoodData Central data are public domain / CC0 1.0. The in-app list identifies USDA FoodData Central as its source. Source: https://fdc.nal.usda.gov/

The pack deliberately contains no images. It is a compact nutrition starter list; users can add a photo to any item from the gallery or camera. Do not add third-party food photographs unless their licence permits redistribution in exported lists.

Slovak display names are edited individually for readability. The word “raw” is omitted at the user's request; cooked, dried, canned and other meaningful preparation differences remain. English source descriptions, FDC IDs and nutrition values are retained. Brand and cultivar names remain identifiable.

`legacySkName` retains the previous AI-generated Slovak label solely for migrating existing imports. Migration matches the old food name and all nutrition/weight fields, including renamed libraries and items moved to other lists. It also runs when importing older JSON backups. It preserves IDs, images, categories, timestamps and unrelated foods, and saves a backup before updating existing names.

Terminology checks for less familiar foods: [USDA seed descriptions](https://www.ars.usda.gov/ARSUserFiles/80400535/Data/SR/SR28/reports/sr28fg12.pdf) distinguish breadfruit from ramón (Brosimum alicastrum); the [CFIA fish list](https://active.inspection.gc.ca/scripts/fssa/fispoi/fplist/fpresults.asp?cbShowAll=on&cmbIn=e&q=crab) identifies queen crab as snow crab.
